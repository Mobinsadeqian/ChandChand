# ⚽ **چندچند (ChandChand)**
> **سامانه هوشمند و زنده نتایج، جدول و اخبار فوتبال**

---

### 📌 **درباره پروژه**
**چندچند** یک وب‌سرویس و اپلیکیشن آنلاین هوشمند است که با فریم‌ورک **Django** طراحی شده است. این سامانه به صورت اتوماتیک آخرین نتایج مسابقات فوتبال، جدول وضعیت تیم‌ها و اخبار ورزشی را از APIهای معتبر بین‌المللی دریافت کرده و با ساختاری کاملاً فارسی و بهینه‌سازی‌شده برای کاربران به نمایش می‌گذارد.

---

### 🚀 **ویژگی‌های کلیدی**

* 🔄 **همگام‌سازی ۱۰ دقیقه‌ای:** به‌روزرسانی زنده و خودکار داده‌های مسابقات بدون نیاز به مداخله دستی
* ⚡ **معماری بهینه Cron Webhook:** اجرای اندپوینت‌های زمان‌بندی‌شده برای کاهش مصرف RAM و سازگاری کامل با هاست‌های رایگان
* 📱 **طراحی کاملاً واکنش‌گرا (Responsive):** نمایش بهینه روی تمامی دستگاه‌ها (موبایل، تبلت و دسکتاپ)
* 🎨 **رابط کاربری راست‌چین (RTL):** طراحی اختصاصی فارسی همراه با آیکون‌ها و استایل‌های متناسب ورزشی

---

### 🛠️ **تکنولوژی‌ها و ابزارها**

* 🐍 **Backend:** Python 3.13 / Django 5.x
* 🗄️ **Database:** SQLite3 / PostgreSQL
* 🌐 **Hosting & WSGI:** PythonAnywhere / Gunicorn
* ⏱️ **Automation:** cron-job.org Webhook Service

---

### ⚙️ **راه اندازی و اجرای لوکال**

۱. **کلون کردن مخزن پروژه:**
```bash
git clone [https://github.com/mobinsadeqian/ChandChand.git](https://github.com/mobinsadeqian/ChandChand.git)
cd ChandChand
```

۲. **ایجاد و فعال‌سازی محیط مجازی:**
```bash
python -m venv venv
# در لینوکس/مک:
source venv/bin/activate
# در ویندوز:
venv\Scripts\activate
```

۳. **نصب وابستگی‌ها:**
```bash
pip install -r requirements.txt
```

۴. **اجرای مایگریشن‌ها و روشن کردن سرور:**
```bash
python manage.py migrate
python manage.py runserver
```

*(سپس آدرس http://127.0.0.1:8000 را در مرورگر باز کنید).*

---

### 🔄 **مکانیسم به‌روزرسانی خودکار (Automation Workflow)**

این پروژه از یک سرویس فراخوانی امن برای به‌روزرسانی دیتابیس بهره می‌برد:

```http
GET /api/cron/update-matches/?token=YOUR_CRON_TOKEN
```

سرویس Cron خارجی هر ۱۰ دقیقه یک‌بار این آدرس را صدا زده و نتایج جدید مسابقات را مستقیماً در دیتابیس ثبت می‌کند.
